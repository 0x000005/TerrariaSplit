# WorldGeneration 说明

## 职责
- 本目录负责金字塔种子预筛入口、世界种子 metadata、金字塔/箱子结果模型和世界生成模拟的项目内接口。
- `Simulation/` 是官方生成流程的局部复刻实现；本层负责把结果整理成主程序可消费的预测。

## 设计原则
- 当前预筛目标范围是小世界、猩红、无特殊/秘密种子；不支持的 scope 要明确返回 unsupported，不做模糊猜测。
- 预筛结果应同时表达状态、是否有目标金字塔、是否符合物品要求、物品摘要和耗时，避免调用方再次猜测细节。
- 修改筛选逻辑必须能追溯到官方生成机制、局部模拟差异或已验证的解析错误；数据集指标只用于验证，不作为规则来源。
- 金字塔和箱子语义保持一致：模拟建出金字塔时，箱子/物品结果应来自同一套模拟或世界文件扫描契约，不新增独立的“无箱子金字塔”业务分支。
- 不在这里做 Terraria 窗口点击、文件删除或 UI 展示；这些由 `Automation/`、Storage 或 UI 层处理。

## 验证
- 修改 `PyramidSeedPreScreen`、结果模型或物品匹配后，运行 `Pyramid seed pre-screen` 聚焦测试。
- 涉及 FP/FN 或耗时的改动，运行 Release `pyramid-metrics`，并记录数据集、FP、FN、itemMismatch、avg/p95。
