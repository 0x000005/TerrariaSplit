2. BOSS

2.1 BOSS 分组（BOSS Groups）

这一页决定哪些 BOSS 参与计时，以及它们属于哪个分段组。

列说明：

  • 启用：是否把该 BOSS 计入路线。
  • 分组：分段编号；整数部分相同的 BOSS 会被视为同一大段。

默认路线：

BOSS 启用 默认分组
骷髅王 开启 1
血肉墙 开启 2
毁灭者 开启 3.1
机械骷髅王 开启 3.2
双子魔眼 开启 3.3
世纪之花 开启 4
石巨人 开启 5
拜月教徒 开启 6
月亮领主 开启 7

2.2 BOSS 图标（BOSS Icons）

这一页为每个 BOSS 指定自定义图标路径。
默认使用内置图标。

设置项 功能 默认值

4. 界面（UI）

通用列说明：

  • 显示：是否显示这一列。
  • 宽度：列宽。
  • 字体大小：文字或图标尺寸。
  • 粗体：是否加粗。
  • 不透明度 %：透明度。
  • 阴影 %：阴影强度。
  • 描边 %：描边厚度。

4.1 分段显示器（Split display）

共有 3 行：图标、时间、差值。

默认值：

行 显示 宽度 字体大小 粗体 不透明度 % 阴影 % 描边 %
图标 开启 240 55 无 100 无 无
时间 开启 180 13.5 开启 100 0 0
差值 开启 150 13.5 开启 100 0 0

附加选项：

设置项 功能 默认值
差值时间单位动态调整 差值会按大小自动切换显示精度。 开启

4.2 主计时器（Main timer）

共有 2 行：小数点前、小数点后。

默认值：

行 显示 字体大小 粗体 不透明度 % 阴影 % 描边 %
小数点前 开启 36 开启 100 0 0
小数点后 开启 24 开启 100 0 0

偏移设置：

设置项 功能 默认值
水平偏移 整体左右微调主计时器位置。 165
垂直偏移 整体上下微调主计时器位置。 0

6.2 加载世界（Load World）

这一页有 10 个练习槽位，键位显示为 1 到 9 和 0，当配置了对应槽位的任意一个文件和名称后，在泰拉瑞亚主界面按下快捷键即可选择槽位并将对应文件复制到泰拉瑞亚存档目录。

每个槽位包含：

  • 名称
  • 人物文件
  • 世界文件

默认全部为空。
