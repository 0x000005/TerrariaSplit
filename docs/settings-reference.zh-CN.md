# 软件设置说明

## 设置层级总览

```text
设置
├─ 常规（General）
├─ BOSS
├─ 数据（Data）
├─ 界面（UI）
├─ 效果（Effects）
├─ 自动化（Automation）
├─ 声音（Sounds）
├─ 颜色（Colors）
├─ 高级（Advanced）
└─ 调试（Debug）
```

## 1. 常规（General）

### 1.1 通用（Common）

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 语言 | 切换界面语言。 | 中文 |
| 全局缩放 % | 统一缩放整个计时器界面。 | `100` |
| 置顶显示 | 让计时器窗口保持在其他窗口上方。 | 开启 |

### 1.2 快捷键（Hotkeys）

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 暂停 / 继续 | 暂停或恢复计时。 | `F12` |
| 重置（在世界内不生效） | 在主菜单时重置计时。 | `F6` |
| 鼠标穿透 | 切换窗口鼠标穿透。 | `F9` |
| 创建世界（在世界内不生效） | 触发自动创建世界流程。 | `F7` |
| 加载世界（在世界内不生效） | 触发练习存档加载流程。 | `F8` |

### 1.3 特殊选项（Special Options）

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 允许手动修改时间 | 开启后可手动编辑总时间或分段时间。 | 开启 |
| 鼠标穿透指示 | 在主计时器旁显示穿透状态提示点。 | 关闭 |

## 2. BOSS

### 2.1 BOSS 分组（BOSS Groups）

这一页决定哪些 BOSS 参与计时，以及它们属于哪个分段组。

列说明：

- `启用`：是否把该 BOSS 计入路线。
- `分组`：分段编号；整数部分相同的 BOSS 会被视为同一大段。

默认路线：

| BOSS | 启用 | 默认分组 |
| --- | --- | --- |
| 骷髅王 | 开启 | `1` |
| 血肉墙 | 开启 | `2` |
| 毁灭者 | 开启 | `3.1` |
| 机械骷髅王 | 开启 | `3.2` |
| 双子魔眼 | 开启 | `3.3` |
| 世纪之花 | 开启 | `4` |
| 石巨人 | 开启 | `5` |
| 拜月教徒 | 开启 | `6` |
| 月亮领主 | 开启 | `7` |



### 2.2 BOSS 图标（BOSS Icons）

这一页为每个 BOSS 指定自定义图标路径。
默认使用内置图标。

## 3. 数据（Data）

### 3.1 参考数据（Reference Data）

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 参考时间使用 PB | 直接把个人累计最佳当作参考时间。 | 关闭 |
| 当前组 | 当前正在编辑或使用的参考时间组。 | `WR` |
| 新组名 | 新建参考时间组的名称输入框。 | 留空 |



### 3.2 个人数据（Personal Data）

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 自动更新个人数据 | 跑完后自动写入新的个人数据。 | 开启 |
| 更新个人数据前询问 | 写入个人数据前先弹窗确认。 | 开启 |

### 3.3 个人累计最佳（Personal Cumulative Best）

勾选自动更新个人数据后，总成绩有效且领先于当前pb时候会更新全部，并生成新的个人累计最佳文件。

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 当前文件 | 可以选择当前使用的个人累计最佳文件。 | `Personal` |

默认各项时间为空。

### 3.4 个人分段最佳（Personal segment best）

此处分组参照2.1中的设置。

勾选自动更新个人数据后，有效且领先于当前pb的分段时间会被更新，并生成新的个人分段最佳文件。

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 当前文件 | 可以选择当前使用的个人分段最佳文件。 | `Personal` |

默认各项时间为空。

## 4. 界面（UI）



通用列说明：

- `显示`：是否显示这一列。
- `宽度`：列宽。
- `字体大小`：文字或图标尺寸。
- `粗体`：是否加粗。
- `不透明度 %`：透明度。
- `阴影 %`：阴影强度。
- `描边 %`：描边厚度。

### 4.1 分段显示器（Split display）

共有 3 行：`图标`、`时间`、`差值`。

默认值：

| 行 | 显示 | 宽度 | 字体大小 | 粗体 | 不透明度 % | 阴影 % | 描边 % |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 图标 | 开启 | `240` | `55` | 无 | `100` | 无 | 无 |
| 时间 | 开启 | `180` | `13.5` | 开启 | `100` | `0` | `0` |
| 差值 | 开启 | `150` | `13.5` | 开启 | `100` | `0` | `0` |

附加选项：

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 差值时间单位动态调整 | 差值会按大小自动切换显示精度。 | 开启 |

### 4.2 主计时器（Main timer）

共有 2 行：`小数点前`、`小数点后`。

默认值：

| 行 | 显示 | 字体大小 | 粗体 | 不透明度 % | 阴影 % | 描边 % |
| --- | --- | --- | --- | --- | --- | --- |
| 小数点前 | 开启 | `36` | 开启 | `100` | `0` | `0` |
| 小数点后 | 开启 | `24` | 开启 | `100` | `0` | `0` |

偏移设置：

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 水平偏移 | 整体左右微调主计时器位置。 | `165` |
| 垂直偏移 | 整体上下微调主计时器位置。 | `0` |

## 5. 效果（Effects）

### 5.1 击败 BOSS 时点亮图标（Light icons when BOSS defeated）

会在对应 BOSS 被击败后点亮图标，否则图标默认点亮。

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 启用 | - | 开启 |
| 未击败时图标灰度 % | 未击败图标的灰度。 | `80` |
| 未击败时图标亮度 % | 未击败图标的亮度。 | `40` |
| 当前 BOSS 图标灰度额外削弱 % | 当前目标图标减少灰度。 | `0` |
| 当前 BOSS 图标亮度额外增强 % | 当前目标图标增加亮度。 | `0` |

### 5.2 突出显示当前阶段（Highlight current stage）

会突出显示当前所处于的阶段，否则所有行同样大小。

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 启用 | - | 关闭 |
| 放大比例 % | 当前分段的放大倍数。 | `112` |
| 景深强度 % | 当前分段的景深效果强度。 | `45` |

### 5.3 提前显示差值时间（Early delta time）

当前时间接近参考一定时间内就开始显示差值，否则只有BOSS被打败后才会显示。

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 启用 | - | 开启 |
| 相差秒数内显示 | 提前显示的触发阈值。 | `120` 秒 |

### 5.4 差值时间渐变（Delta time gradient）

会根据差值时间的正负与大小采取渐变过渡。

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 启用（历史差值） | 给历史差值列启用渐变色。 | 开启 |
| 启用（当前差值） | 给当前差值与BOSS动画启用渐变色。 | 开启 |
| 启用（主计时器） | 给主计时器启用渐变色。 | 开启 |
| 阈值时间 | 多大差值开始拉满渐变。 | `120` 秒 |
| 渐变方式 | 渐变曲线模式。 | `Soft step` |

### 5.5 BOSS 击败动画（BOSS defeat animation）

在BOSS被击败后显示动画。

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 启用 | 击败 BOSS 后播放结算动画。 | 开启 |
| 动画时长（秒） | 控制动画持续时间。 | `7` |
| 描边 % | 动画描边厚度。 | `40` |

## 6. 自动化（Automation）

### 6.1 创建世界（Create World）

#### 6.1.1 角色与世界基础参数

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 人物名 | 自动创建人物时使用的名字。 | 空，表示 `1` |
| 人物难度 | 自动创建人物的难度。 | `Softcore`（软核） |
| 人物代码 | 粘贴人物模板代码。 | 空，表示默认人物 |
| 世界大小 | 自动创建世界的大小。 | `Medium`（中） |
| 世界难度 | 自动创建世界的难度。 | `Classic`（经典） |
| 世界邪恶 | 自动选择腐化 / 猩红 / 随机。 | `Random`（随机） |

#### 6.1.2 种子与附加流程

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 彩蛋种子 | 勾选特殊世界种子。 | 不勾选任何项 |
| 隐藏种子 | 直接填写提交给 Terraria 的种子字符串。 | 空 |
| 启用自动接星星（仅天顶世界有效） | 天顶世界创图时自动接星。 | 关闭 |
| - 在以下阶段后停止 | 自动接星流程停止阶段。 | `Pots`（罐子） |
| - 接星速度 | 自动接星速度。 | `5.0x` |
| 自动筛选金字塔 | 创建完成后自动筛选金字塔，若无，则重新创图直到有。 | 关闭 |


### 6.2 加载世界（Load World）

这一页有 10 个练习槽位，键位显示为 `1` 到 `9` 和 `0`，当配置了对应槽位的任意一个文件和名称后，在泰拉瑞亚主界面按下快捷键即可选择槽位并将对应文件复制到泰拉瑞亚存档目录。

每个槽位包含：

- 名称
- 人物文件
- 世界文件

默认全部为空。


### 6.3 延迟（Delay）

控制自动点击操作之间的延迟。

| 设置项 | 功能 | 默认值 |
| --- | --- | --- |
| 鼠标 / 按键按下 ms | 单次模拟按下鼠标持续时间。 | `140` |
| 窗口激活等待 ms | 激活 Terraria 窗口后的等待时间。 | `10` |
| 点击聚焦等待 ms | 点击后等待窗口接收焦点。 | `10` |
| 短操作延迟 ms | 同页面相邻点击步骤之间的间隔。 | `10` |
| 菜单操作延迟 ms | 菜单切换步骤之间的等待。 | `90` |
