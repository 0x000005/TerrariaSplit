# TerrariaSplit 产品与交互设计文档

> 适用版本：`1.13.0.0+` · 文档职责：定义 **TerrariaSplit** 的领域语义、计分与对比规则、Overlay 视觉与动效体系、管理窗口 UI 规范、自动化/筛选产品规则与联机竞速体验。  
> 系统分层、线程拓扑与工程实现见 [ARCHITECTURE.md](ARCHITECTURE.md)；开发纪律见 [AGENTS.md](../AGENTS.md)；原生筛选器协议见 `../../TerrariaResourceJudge/docs/ABI.md`。

## 1. 设计目标与产品原则

TerrariaSplit 面向 Terraria 速通、日常分段练习、自动化刷图与多人联机竞速场景，核心体验原则如下：

1. **游戏内零干扰与全背景可读**：主界面为无边框、纯透明底的像素级 Alpha 浮层，支持一键鼠标穿透与全屏 RTSS OSD 降级，通过 3x 超采样描边与阴影保证在白天、地下、地狱等任意游戏亮度下清晰锐利。
2. **高密度信息、低视觉噪点**：默认以紧凑像素图标 + 累计时间 + 动态差值（Delta）呈现路线，当前阶段通过图标提亮与景深聚焦自动突出，无需视线离开游戏主画面。
3. **三种运行态语义清晰**：
   - **普通速通模式**：纯只读监控、支持自动创图/世界池与自动记录 PB；
   - **练习模式**：允许直接点击编辑单段/总时间，配合练习存档快速分段训练；
   - **竞速模式**：严格锁定版本/世界/路线与公平性规则，禁用一切会干扰比赛一致性的本地操作。
4. **跨版本优雅降级**：普通功能按 `1.4.4` / `1.4.5` / `1.4.6+` 版本组尽量兼容；竞速功能涉及进程内 Hook 与公平性，必须精确匹配已登记构建，宁可拒绝也不弱化校验。

## 2. 计时与路线语义设计

### 2.1 计时生命周期
- **自动起表**：仅在计时器处于未开始（`NotStarted`）状态，监测到 `Terraria.exe` 由菜单进入世界（`Main.gameMenu` 从 `true` 变为 `false`）时自动从 `0:00.00` 开始计时并播放进图音效；计时进行中或暂停时重新进入世界不会重置当前计时。
- **暂停 / 恢复**：仅在已起表（`Running` / `Paused`）时生效，分别播放暂停与恢复音效；竞速模式下禁用暂停。
- **自动停表与收尾**：当路线中全部主分组完成时自动停表并触发一次运行统计采集；手动重置或切换设置时触发收尾结算（统计 + PB 评估）。

### 2.2 四类条件与三值逻辑
每条路线项（`SplitRouteEntry`）由一棵 `SplitCondition` 条件树驱动：

- **四类事实来源（`SplitTargetKind`）**：
  - `Boss`：17 个 Boss 击败标志与肉山困难模式（`Hardmode`）；
  - `Item`：玩家持有物品数量，并由领域层自动派生 `item:<id>:ever-owned`（本局历史曾达到的最大持有数），防止物品消耗、合成或丢弃后条件回退；
  - `NPC`：城镇 NPC 到达并入住；
  - `Biome`：玩家进入指定生物群系（来自 `Player.zone1~zone5`）。
- **组合逻辑与三值求值**：
  - 支持单事实比较（`IsTrue` / `IsFalse` / `AtLeast` / `Equal`）与多目标组合（`All` 全部完成、`Any` 任意完成、`AtLeast` 至少完成 N 个）；
  - 每次求值返回 `Unknown` / `False` / `True` 三态，避免内存尚未就绪时误判。
- **开局防误触（Initial State Resolution）**：
  - 起表瞬间若某分段的条件已经为 `True`（例如读入已击杀前序 Boss 的练习档），自动标记为 `Skipped` 而非以 `0:00` 误完成；仅当明确观测到条件为 `False` 后才允许后续触发完成。

### 2.3 主分组与附属分组（Main vs Attached）
| 维度 | 主分组（`IsAttached = false`） | 附属分组（`IsAttached = true`） |
|---|---|---|
| **推进顺序** | 严格有序推进；完成后续主分组会自动将中间未完成段标记为 `Skipped`。 | 挂载于当前主阶段之前；仅在前置所有主分组均已完成或跳过时开放检测。 |
| **显示策略** | 始终按可见窗口规则展示。 | 开启 `AutoHideAttachedGroups` 时，未开放阶段自动折叠隐藏，开放或全通后按配置展开。 |
| **过场动画** | 完成后触发 Boss 击败 / 分段完成过场动画。 | **不触发**过场动画，避免打断主节奏。 |
| **PB / 单段计算** | 参与单段最佳与累计 PB 资格判定。 | 不参与单段最佳（统计表对应单段列显示 `--`）。 |

### 2.4 显示裁剪与多条件展开策略
- **可见分组窗口**：启用 `EnableVisibleGroupCountLimit` 后按 `VisibleGroupCountLimit`（默认 `5`）与 `CurrentGroupPosition`（默认第 `3` 行）滚动窗口，可固定显示末段（`ShowFinalGroup`），并在通过末段后按配置展开全部可见分组、附属分组及多条件主分组。
- **多条件详情行**：启用 `ExpandSplitDetails` 后，可将含多子条件的分段按子条件拆行显示各自进度与时间，并支持 `CollapseSplitDetailsOnCompletion` 在整段完成后自动折叠回单行。

## 3. 对比、PB 结算与统计设计

### 3.1 参考时间与实时差值（Delta）
- **参考时间源**：支持多套参考时间集（默认内置 `WR`），也可勾选 `UsePersonalBestAsReferenceTime` 直接以当前累计 PB 作为参考基准。
- **提前差值显示**：当前正在进行的分段在距参考时间不足 `EarlyDeltaTimeSeconds`（默认 `120s`）或已超时后，实时展示动态 Delta；开启 `EnableDynamicDeltaTimeUnits` 后按绝对值大小自动切换秒（如 `+47.2`）与分:秒（如 `-2:07`）格式。

### 3.2 自动 PB 与单段最佳结算规则
- **累计 PB（Personal Best Time）更新条件**：
  1. 启用 `AutoUpdatePersonalBestData`；
  2. 所有主分组均已完成且**无任何跳过**；
  3. 当前路线最后一个已启用主分段的累计完成时间严格快于该分段的现有 PB（或尚无记录），随后保存整条路线的累计成绩。
- **单段最佳（Personal Best Segment）更新条件**：
  - 从首个主分组到最后一个已完成主分组之间**连续无跳过**，凡某主分组单段耗时严格快于现有单段记录，即纳入更新集合。
- **确认与归档**：可配置 `AskBeforeUpdatingPersonalBestData` 控制自动静默更新或弹窗确认；每次更新同时归档为独立的命名快照集（`PersonalBestTimeSets` / `PersonalBestSegmentSets`），便于在统计页面回溯历史记录。

### 3.3 练习模式与统计页面
- **练习模式（`PracticeMode`）**：
  - 允许在主浮层直接点击单段或总时间弹出 `ModernTimeEditDialog` 修改时间；
  - 修改单段时自动保持时间序列单调递增（不得早于前序已完成段，且自动推高后续更早的已完段）；修改总时间时自动将超过总时间的已完成段钳制到总时间；
  - 进入竞速房间后自动禁用编辑。
- **统计页面（`StatisticsWindow`）**：
  - 顶部提供 **选择一局**（左）与 **参考局**（右）双下拉选择器，下方展示汇总卡（`本局`、`参考`、`PB`、`Sum of Best`）；启用“使用 PB 作为参考时间”时隐藏 `PB` 卡片与表中两列 PB 时间、并将 `本局` 卡片扩为两格宽；单段最佳不完整时隐藏 `Sum of Best` 卡片；参考或本局时间不完整时保留显示 `--`；
  - 表格按路线顺序呈现 **分段 | 该局累计时间 | 参考累计时间 | 个人最佳累计时间 | 该局单段时间 | 参考单段时间 | 个人最佳单段时间**（不含差值列），各时间列按等宽数字右对齐后整块居中于居中表头下；
  - 右侧单段时间单元格自动向上合并其上方所有附属分组及同主分组多条件子行直至上一个主分组下方，直接标明完整的一段；动图（`.gif`）与垂直帧序列物品图标仅显示第 1 帧。

## 4. Overlay 视觉系统与动效设计

主浮层视觉参考 LiveSplit 的分段排版与 `terraria-boss-checklist` 的像素图标点亮理念（预览见 [readme-main.png](images/readme-main.png)）。

### 4.1 排版结构与四列体系
- **纵向结构**：上方为 Split 分段列表，下方为大字号主计时器（主时间 + 较小字号毫秒 `.03`）；支持全局缩放 `ScalePercent`（`25%–300%`）。
- **四列可配布局**：`Icon`、`Name`（默认隐藏）、`Time`、`Delta` 均支持独立开关、列宽、对齐方式（`Left` / `Center` / `Right`）、字族、字号、粗体/斜体及列间距，且**主分组与附属分组各自拥有一套独立样式配置**。
- **多目标横排与图标覆盖**：单行包含多个目标（如机械三王、四柱）时，图标在 `Icon` 列内横向并排；支持按全目标（`All`）、单一指定目标（`Target`）或自定义图片文件（`CustomFile`）覆盖显示图标。

### 4.2 色彩、渐变曲线与特效体系
- **语义色板（`UiPalette`）**：每类文本均独立配置填充色（Fill）、描边色（Outline，默认 `#101010`）与阴影色（Shadow，默认纯黑）：
  - 分段名称：普通白 `#FFFFFF` / 当前蓝 `#0075EC` / 已完成橙金 `#F0A040`；
  - 分段时间：参考灰 `#C8C8C8` / 当前参考金黄 `#FFD35A` / 已完成橙金 `#F0A040`；
  - 差值 Delta：领先绿 `LightGreen` / 持平白 `White` / 落后红 `LightCoral`；
  - 主计时器：默认白 `#F2F2F2` / 领先绿 / 落后红 / 破纪录蓝 `#69A7FF` / 无纪录红 `Red` / 暂停浅灰 `Gainsboro`。
  - 最后一个已启用主分段完成后，有对应参考时间时以该主分段的累计时间判断最终配色：严格更快使用破纪录色，否则使用未破纪录色；中途完成月球领主不提前触发最终配色。这里比较的是当前参考时间，不等同于累计 PB 的保存资格。
- **差值动态渐变（Delta Gradient）**：可分别对已完成 Delta、当前运行 Delta 与主计时器启用渐变，以 `DeltaGradientThresholdSeconds`（默认 `120s`）为满色阈值，提供 4 种插值曲线：
  - `Linear`（线性）、`Smooth`（平滑 S 曲线）、`HardStep`（硬阶跃）、`SoftStep`（默认软阶跃）。
- **单段最佳高亮（Segment Best Delta Highlight）**：当某段打破单段最佳时，可按分段配置动态高亮风格：`None`、`Rainbow`（界面显示为 `Neon`）与 `Aurora`（界面显示为 `Breathe`）。
- **描边与阴影参数**：图标、名称、时间、Delta、主计时器、毫秒均分别提供 `OpacityPercent`、`ShadowPercent`、`OutlineThicknessPercent` 三个百分比滑块，渲染端采用 3x 超采样保证边缘干净。

### 4.3 图标点亮与当前阶段景深聚焦
- **三态图标点亮（`EnableDefeatedBossIconLighting`）**：
  - 未完成目标：按 `UndefeatedIconGrayscalePercent`（默认 `80%`）去饱和并按 `UndefeatedIconBrightnessPercent`（默认 `40%`）压暗；
  - 当前阶段目标：减弱去饱和（默认 `40%`）并提亮（默认 `35%`）；
  - 已完成目标：100% 全彩原亮度点亮（多目标行中按每个子条件的独立完成状态逐个点亮）。
- **当前阶段景深系统（Current Split Depth）**：
  - 开启 `ShowCurrentSplitHighlight` 且计时器运行中时，焦点行按 `CurrentSplitHighlightScalePercent`（范围 `100%–140%`，默认 `112%`）放大，相邻行按距离衰减（距离 `0 / 1 / 2 / 3 / 4+` 对应放大权重 `1.00 / 0.58 / 0.28 / 0.10 / 0.00`）；
  - 同时按 `CurrentSplitDepthStrengthPercent`（默认 `45%`）逐层降低远离焦点行的不透明度（衰减阶梯 `0% / 24% / 46% / 62% / 72%`），形成聚焦景深层次。

### 4.4 Boss 击败 / 分段完成过场动画
- 完成主分段时，在列表区（至少预留 7 行高度）平滑覆盖播放过场动画（默认时长 `4.2s`，可配 `2s–20s`）：
  - **淡入淡出**：首尾各 `0.45s` `EaseInOut` 透明度过渡；
  - **主视觉元素**：放大居中展示完成目标图标，右侧并排显示累计时间与单段耗时对比（按分段配置开关）；
  - **错峰位移动效**：Delta 差值文本在主体淡入后再延迟 `0.06s` 伴随横向滑动（`10–20px`）揭示，并在主体淡出前提前滑出；
  - **动态描边**：累计与单段完成行可各自配置动态描边样式（`None` / `Rainbow` / `Aurora` / `Gold`）。

### 4.5 音效与全屏 OSD 反馈
- **差异化音效矩阵（`SplitSoundSelector`）**：
  - 进图、暂停、恢复、重置各自拥有独立音频槽；
  - 分段完成按 **“累计是否领先参考 × 单段是否快于单段最佳”** 构成 2×2 四种音效（`Ahead/Behind Reference × Ahead/Behind Segment`），末段完成还可配置独立的 2×2 终结音效覆盖。
- **RTSS 全屏 OSD 降级**：在独占全屏下，输出去装饰的紧凑文本（计时器 + 当前阶段与差值），复用语义色彩，确保全屏玩家仍能获得核心计时反馈。

## 5. 管理窗口 UI 设计系统（Settings / Statistics / Race）

### 5.1 Windows 11 Fluent 2 Dark 紧凑视觉规范（WPF `UI/Wpf/Theme`）
所有管理窗口（`SettingsWindow`、`RaceWindow`、`StatisticsWindow`、`PracticeWorldPaletteWindow` 与 `ModernMessageDialog` / `ModernTimeEditDialog`）统一采用基于 `.NET 10` 官方 `PresentationFramework.Fluent`（`Fluent.Dark.xaml`）底座的 **Windows 11 Fluent 2 Dark** 紧凑桌面视觉体系，启用原生 DWM 深色模式、窗口圆角、**Mica**（主窗口）/ **Acrylic**（练习世界面板）背景材质与极简无多余装饰的单套标题栏控件：

| 语义角色 | 色值 / 材质 | 用途 |
|---|---|---|
| `WindowBg` / `PageLayerBg` | `#202020` + Win11 Mica（内容区采用不透明中性层启用硬件 ClearType） | 窗口主画布、无边框标题栏与页面背景层 |
| `SidebarBg` / `Surface` | `#242424` / `#2B2B2B` | 左侧导航栏、设置卡片与数据表格表面 |
| `ControlFill` / `Field` | `rgba(255,255,255,0.06)` / `#252525` | 按钮、输入框、下拉框与数字框表面 |
| `Border` / `Divider` | `rgba(255,255,255,0.08)` | 1px 卡片边框、行间分隔线与控件描边 |
| `Accent` | `#60CDFF`（Hover `#78D6FF` / Pressed `#4CC2FF`） | 主操作按钮、激活态 Toggle、选中导航指示条与焦点下划线 |
| `TextPrimary` / `TextSecondary` | `#FFFFFF` / `#C5C5C5` | 正文、行标签与次级表头/禁用态文字（警告提示直接采用黄字 `#F5C97B`，不额外套框） |

所有 WPF 管理窗口遵循 **紧凑桌面密度令牌**（`TitleBarHeight = 34`、`ControlHeight = 26`、`Toggle = 36×18`、`SettingRowHeight = 36`、`TableRowHeight = 34`、`TableHeaderHeight = 28`、`NavItemHeight = 30`）、静态清晰字体（`Segoe UI, Microsoft YaHei UI` + 动态高 DPI `TextFormattingMode`）与原生 Per-Monitor DPI 矢量缩放；全站表格除首列外统一表头居中，常规设置行与表格行各自保持统一行高；仅保留透明排行榜浮窗 `RaceLeaderboardForm` 沿用 WinForms 渲染与 `UiDpiScale`。

### 5.2 主浮层交互入口与 10 页设置信息架构
- **主浮层右键菜单（`MainFormContextMenuBuilder`）**：
  - `统计...`、`竞速...`、`设置...`、`种子筛选`（快捷勾选开关）、`切换配置`（动态列出 `Settings/` 下全部有效配置文件并标记当前项）、`退出`。
- **全局热键（`HotkeySettings`）**：暂停/恢复（默认 `F8`）、重置（默认 `F6`）、鼠标穿透（默认 `F9`）、一键创图、练习世界、手动分片；注册冲突时弹出 `ModernMessageDialog` 明确提示。
- **10 页设置导航（`SettingsWindow`）**：
  1. `General`：语言（中/英）、置顶、鼠标穿透指示器、练习模式、6 组全局热键；
  2. `Splits`：可视化路线编辑器——支持拖拽排序、全目标搜索（Boss/物品/NPC/群系）、主/附切换、基础勾选与高级条件树编辑、图标覆盖与分组裁剪策略；
  3. `Data`：参考时间集与个人最佳（累计/单段）管理、导入/切换、自动更新 PB 开关；
  4. `Ui`：Overlay 缩放、各列显隐/宽度/对齐/字体/间距、主/附两套参数；
  5. `Effects`：文本与图标描边/阴影/透明度、图标点亮、景深聚焦、差值渐变曲线、单段最佳高亮、Boss 击败过场动画；
  6. `Automation`：人物/世界默认参数、彩蛋与秘密种子、存档备份/保留、后台世界池容量、多条件种子筛选面板、Zenith 自动接星；
  7. `Sounds`：各事件与 2×2 分片音效配置；
  8. `Colors`：完整语义色板编辑器；
  9. `Advanced`：手动分片开关与热键、Terraria UI 缩放增强（300%）、RTSS 全屏投影开关/路径/坐标/缩放、四项采样与渲染刷新率配置、日志最低级别（`DEBUG` / `INFO` / `WARN` / `ERROR`[默认] / `不记录日志`）及一键**导出诊断信息（ZIP）**；
  10. `About`：版本信息、GitHub 检查更新、下载进度与一键重启更新。

### 5.3 故障反馈与日志体验设计
- **默认静默、出错自动回溯**：默认仅在发生 `ERROR` 时写入磁盘，但平时仍在内存中保留最近 60 秒（最多 8 MiB）的全级别轨迹；一旦操作失败或发生异常，自动把出错前 60 秒的上下文完整补录到 `terrariasplit.log`，用户无需先手动开 Debug 再复现即可直接排查。
- **一键导出诊断包**：在 **设置 → 高级 → 日志** 或自动化失败弹窗中点击 **导出诊断信息**，生成包含环境信息、依赖指纹、近期内存轨迹与轮转日志的 `.zip` 诊断包；错误弹窗提供含 `Error ID`、`Failure code`、`Operation/Stage` 与原因的可复制文本报告（日志消息、事件码与报告统一使用英文，独立于界面语言）。
- **关闭日志语义**：选择“不记录日志（`NONE`）”后立即清空内存缓冲并停止采集与自动回溯，但保留已有磁盘文件；手动导出仍可打包已有日志与当前错误报告。

## 6. 自动化与世界筛选产品规则

### 6.1 一键创图、练习存档与 Zenith 自动接星
- **存档安全策略**：默认创图前将非收藏人物与世界移入备份目录，保持选单整洁；勾选 `PreserveExistingSaves` 后仅统计现有存档而不移动任何文件。
- **后台世界池心智**：启用后后台静默预筛并生成匹配当前配置的成品世界；按下创图热键时直接拷贝安装池中成品并停在选图界面，实现“零等待开局”。任何影响生成结果的选项变更都会自动作废旧池并重新预热。
- **Zenith 自动接星**：在 GetFixedBoi/Zenith 彩蛋世界创建加载界面自动接取落星，提供 6 个可配停止阶段（`Life Crystals` / `Statues` / `Buried Chests` / `Gem Caves` / `Pots`[默认] / `Traps`）与对数刻度速度滑块（`1.0x–50.0x`，默认 `5.0x`）。

### 6.2 多尺寸种子筛选规则与基准换算
- **适用范围**：支持小/中/大世界、猩红/腐化、四种游戏模式；**固定种子模式禁用随机筛选**；随机邪恶会在每个候选先解析为具体邪恶类型，地牢侧猩红条件仅在猩红候选中提交。
- **逻辑组合**：不同条件之间为 **AND**；金字塔物品（沙暴瓶 / 飞毯 / 法老套）之间为 **OR**，且金字塔物品、金币堆与入口覆土深度必须由 **同一座金字塔** 满足；丛林物品（三发猎枪 / 猛爪手套 / 疾风脚镯）之间为 **AND**。
- **小世界基准存储与多尺寸换算**：设置与竞速协议只存储小世界基准档位（切换尺寸不会重复缩放），调用原生 DLL 前由托管端换算实际格数（横向距离向下取整），资源代价上限由 DLL 按世界高度缩放：

| 筛选条件 | 小世界 (`4200×1200`) | 中世界 (`6400×1800`) | 大世界 (`8400×2400`) |
|---|---|---|---|
| 金字塔锚点 X（含边界，30%–70%） | `1260–2940` | `1920–4480` | `2520–5880` |
| 金字塔入口覆土深度上限（中/浅/露天） | `30 / 15 / 2` 格 | `30 / 15 / 2` 格 | `30 / 15 / 2` 格 |
| 地牢侧猩红最大横向距离 | `525 / 945 / 2100` | `800 / 1440 / 3200` | `1050 / 1890 / 4200` |
| 星怒箱最大横向距离 | `100 / 200 / 300` | `152 / 304 / 457` | `200 / 400 / 600` |
| 雀杖箱最大横向距离 | `300 / 500 / 800` | `457 / 761 / 1219` | `600 / 1000 / 1600` |
| 丛林路线最深世界 Y 下限 | `550 / 650 / 750` | `825 / 975 / 1125` | `1100 / 1300 / 1500` |
| 丛林资源代价上限（严格小于） | `< 50` | `< 75` | `< 100` |

> 各条件对应的固定 Pass 判定时点、早拒策略与空间路线/代价场算法规范见 `../../TerrariaResourceJudge/docs/ABI.md`。

## 7. 联机竞速体验与规则设计

### 7.1 角色流转与房间体验
- **Host（房主）**：创建 4 位数字房号房间，选择世界来源（**随机筛选生成** / **自定义种子生成** / **上传已有 `.wld`**），配置 RNG 控制、Boss 罚时及种子筛选条件；上传世界时同步分发路线、参考时间与自定义图标；控制全房同步开赛（7 秒倒计时）、重开、踢人与关房。
- **Member（成员）**：输入 4 位房号与昵称加入（掉线后支持原昵称自动恢复房间状态）；自动下载并校验 `.wld`、按房间难度自动创建人物（旅途世界强制旅途人物，其余软核，支持人物外观模板码）、勾选准备后随倒计时同步进入世界。

### 7.2 竞速期交互限制（`RaceInteractionPolicy`）
为保证比赛公平与计时完整性：
- **进入竞速房间后**：禁止应用或临时应用本地常规设置（防止中途篡改路线/参考时间）；
- **开启竞速模式后**：禁止暂停计时、禁止切换本地筛选开关、禁止非竞速受控重置、禁止练习模式修改单段/总时间、禁止手动分片，并禁止触发本地普通自动创图与练习世界菜单动作。

### 7.3 公平性与 Boss 失败罚时规则
- **严格构建门禁**：仅允许已登记的 `1.4.6.1` x86 构建（版本号与 `ModuleVersionId` 双重匹配）与 `329` 格式世界文件参与竞速。
- **确定性 RNG 控制**：由服务端下发房间级熵种子，在游戏内统一接管 Boss/怪物掉落、炼金省药、幸运、世界事件、星尘/城镇与世纪之花花苞生成，减少运气方差。
- **Boss 失败罚时公式（`RaceBossPenalty`）**：
  - 针对 8 个关键推进 Boss（`Skeletron`、`Wall of Flesh`、`Destroyer`、`Skeletron Prime`、`Twins`、`Plantera`、`Golem`、`Lunatic Cultist`），可按位独立启用，并支持房主自定义 8 Boss × 4 难度罚时表；
  - 触发 Boss 战失败时，按剩余血量比例计算罚时并直接计入主计时器：
    $$\text{PenaltyMs} = \text{round}\!\left(\left(\text{BaseSeconds} + \text{ProportionalSeconds} \times \min\!\left(1, \frac{\text{CurrentLife}}{\text{MaxLife}}\right)\right) \times 1000\right)$$
  - 默认基准（Classic，单位秒，格式 `基础 + 比例`）：骷髅王 `120+180`、肉山 `120+240`、毁灭者 `120+60`、机械骷髅王 `60+240`、双子魔眼 `120+180`、世纪之花 `180+240`、石巨人 `180+240`、拜月教徒 `180+240`；其余难度按倍率缩放（Journey `0.5×`、Expert `1.25×`、Master `1.5×`）。

### 7.4 多端反馈与竞速界面
- **竞速控制台（`RaceWindow`）**：采用与设置窗口一致的 WPF Fluent 2 侧边导航结构，包含 5 个页面（`Connection`、`Penalty`、`UI`、`Colors`、`Voice`）；开房、加房与准备流程通过游戏内竞速菜单交互完成。
- **实时排行榜浮窗（`RaceLeaderboardForm`）**：与主浮层一致的透明分层窗口，支持鼠标穿透、4 列（排名 / 玩家 / 图标 / 时间）自定义宽距与对齐、排名渐变色，并支持勾选 `UseRankColorForMainTimer` 将实时排名色同步映射至主计时器。
- **游戏内联动与语音播报**：支持直接在 Terraria 菜单界面操作竞速大厅与准备流程；选手完成关键分组、死亡或重置进度时，同步向游戏内推送消息并可选通过 Windows TTS 语音播报（可配音色、语速与音量）。
