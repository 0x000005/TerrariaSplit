# Configuration 层说明

## 职责
- 这里管理设置模型、默认值、序列化、profile、split set 加载和设置归一化。
- 配置层的目标是让旧配置、缺失配置和非法配置都能安全进入应用。

## 设计原则
- 新增设置项时，同步考虑模型字段、默认值、归一化、序列化兼容、UI 展示和测试。
- 设置读取后应尽早归一化，避免业务层到处处理非法值。
- 配置层只处理数据形状和兼容性，不决定 run state 或 UI 副作用。
- 对用户已有配置保持向后兼容；不能兼容时要有明确迁移或安全回退。
- UI 设置页只负责编辑入口；任何新设置的真实默认值、合法范围和旧配置兼容都应在本目录落地。

## 验证
- 修改设置结构、默认值或归一化逻辑后，运行完整测试命令。
- 新增可视设置时，检查设置窗口是否能读取、修改、保存并再次加载。
